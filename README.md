## Taller TDD-II | Next-Digital

Este proyecto se trata de un pequeño kata de código, basado en el [proyecto](https://github.com/Next-Digital-Hub/next-workshop--tdd-2) incluido en las clases del taller.

Dependencias:
- Java 17
- Docker (a poder ser rootless, e importante especificar versión de API 1.44)
- Testcontainers
- JUnit
- Cucumber
